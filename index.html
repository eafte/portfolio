01 Featured

LLM Guard Bench: Adversarial LLM Security Benchmark

Self-directed research-style project: five attack categories tested against four local models via Ollama (40 pilot-scale runs).

  • Python
  • asyncio
  • aiohttp
  • Pydantic v2
  • Ollama
  • Groq (LLM-as-a-Judge)
  • SQLite + JSONL
  • Docker
  • Benchmarks LLM robustness across five attack categories: prompt injection, DAN jailbreak, roleplay exploitation, refusal bypass, and system-prompt leakage
  • Async pipeline with concurrency control and a two-stage evaluation (keyword heuristics, then LLM-as-a-Judge)
  • Dual persistence (SQLite + JSONL audit trail), retry/backoff, and a reproducible Docker setup
  • MIT licensed, with CITATION.cff and contribution guidelines

Result: across 40 pilot runs (8 per attack category), prompt injection and DAN jailbreaks were the most effective vectors; system-prompt leakage and refusal bypass were fully blocked - 0/8 runs vulnerable across all 4 local models.

04

HarmonyCare: Elderly Safety and Volunteer Response

Android application built with a course team: one-touch emergency alerting for elderly users, and a response and navigation flow for volunteers.

  • Java
  • Android SDK 34
  • Room
  • MVVM
  • Material Design
  • AMap / OSMDroid

My role: a small part of the architecture work. The application itself was built by the team.

  • The app is structured as MVVM with a repository layer over Room, with a data model of eight entities covering alerts, users, chat, ratings, reminders, and offline operations
  • Offline-first alert path: an alert is queued on the device, then broadcast over the local WiFi network, so nearby volunteers can be reached with no server and no internet
  • Accessibility for elderly users: confirmation countdown before sending an alert, text-to-speech and haptic feedback, large-text mode, and English / Bengali localization

Result: a team project delivered as a 17-screen Android application (13,000+ lines of Java) spanning two user roles, in a stack outside my other work.
