LLM Guard Bench: Adversarial LLM Security Benchmark

Empirical evaluation framework: automated adversarial robustness testing across 5 attack categories and 4 local model families using Ollama (40 benchmark runs).

  • Python
  • asyncio
  • aiohttp
  • Pydantic v2
  • Ollama
  • Groq (LLM-as-a-Judge)
  • SQLite + JSONL
  • Docker
  • Evaluates LLM security boundaries across five attack vectors: prompt injection, DAN jailbreaks, roleplay exploits, refusal bypass, and system prompt leakage
  • Asynchronous evaluation pipeline with concurrency control, keyword heuristics, and automated LLM-as-a-Judge verdict classification
  • Dual persistence audit trail using SQLite and JSONL, retry logic with exponential backoff, and a reproducible Docker environment
  • Open-source framework published with strict Pydantic schemas, benchmark reporting, and CITATION.cff metadata

Result: across 40 benchmark runs, prompt injection and DAN jailbreaks achieved the highest vulnerability rates (57% and 50%), while system prompt leakage and refusal bypass remained fully defended at 0% vulnerability across all four local models.
