01 Featured

LLM Guard Bench: Adversarial LLM Security Benchmark

A tool that tests local LLMs against attacks: 40 pilot runs, 5 attack types, 4 Ollama models.

  • Python
  • asyncio
  • aiohttp
  • Pydantic v2
  • Ollama
  • Groq (LLM-as-a-Judge)
  • SQLite + JSONL
  • Docker
  • Async runs with concurrency limits, heuristics, and an LLM judge for verdicts
  • Every run saved to SQLite and JSONL; failed calls retry with backoff; Docker setup so others can repeat the tests
  • Streams 1M+ records with flat memory use (~50.2 MiB peak)
  • Strict Pydantic schemas, strict MyPy, CITATION.cff, and 717 pytest cases

Finding: prompt injection and DAN jailbreaks worked most often; refusal bypass and system-prompt leakage never worked.

ML Host Hardening: Securing an ML Inference Server

Hardening a FastAPI inference service on Ubuntu 24.04 with nginx, a no-login service account, a default-deny firewall, and a systemd sandbox - measured before and after.

  • Ubuntu 24.04
  • nginx
  • FastAPI
  • UFW
  • systemd
  • Lynis
  • SSH
How it works
  • Open ports cut from 22 and 8000 to 22 and 80; nginx forwards only two routes
  • Raised the Lynis hardening index from 61 to 71 and cut the systemd exposure score from 9.2 to 1.4
  • Live sysctl checks found two settings quietly overridden by apport and UFW

Result: every change was measured: ports, Lynis index, and systemd exposure, before and after.

HarmonyCare: Elderly Safety and Volunteer Response

Team-built, 17-screen Android app: one-touch emergency alerts for older users, volunteer response, and local-network alerts without internet.

  • Android SDK 34
